# Jafarali Khan — Personal DevOps Portfolio

A responsive, animated, recruiter-facing portfolio built with HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a **new public GitHub repository** (recommended name: `jafarali-portfolio`).
2. Upload all files and folders in this project to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for deployment and open the published URL shown in the Pages section.

## Recruiter-ready checklist
- Confirm each project repository is public and its README explains the work.
- Check the email, phone number, LinkedIn and Instagram links before sharing.
- Keep the resume PDF current; replace `assets/Jafarali-Khan-Resume.pdf` when you update it.
- Update role dates and project details as your experience changes.
- Share the live website URL and GitHub profile with recruiters.

## Structure
- `index.html` — portfolio content and social/contact links
- `assets/style.css` — responsive styling and motion effects
- `assets/script.js` — mobile navigation, scroll reveal, particles and subtle 3D tilt
- `assets/Jafarali-Khan-Resume.pdf` — downloadable resume
